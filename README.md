# Bagrov Book

Сайт книги Тимофея Багрова: 150 таёжных рецептов.

- Репозиторий: **bagrov-book**
- После деплоя на Vercel: `https://www.timofey-bagrov.ru`
- Свой домен позже: `timofey.bagrov.ru`

## Деплой

1. Этот репозиторий уже готов.
2. На [vercel.com](https://vercel.com) войди через GitHub.
3. Import → **bagrov-book**.
4. Root Directory оставь пустым. Build Command: `npm run build`.
5. Deploy.

Не включай GitHub Pages — сайт собирается под Vercel.
